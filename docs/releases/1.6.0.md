Cinderleaf 1.6.0 brings a more careful way to move mods between your main setup and a sandbox, along with clearer install and recovery checks. The Windows app also has a new icon and another round of English and Brazilian Portuguese polish.

### What changed

- In Compare, choose a mod and review a one-way sync from real Mods to sandbox Mods, or the other way around. The review shows the direction, destination, replacements, and archive location before anything is written. Related folders belonging to one mod stay together.
- Install plans now stop when a package or destination has changed since review. For completed 1.6.0 installs, History checks the installed mod and its archived copy before automatic recovery. If either has changed, Cinderleaf stops rather than overwriting later work.
- Update-source matching and SMAPI log feedback are clearer. Everyday screens have had another layout and copy pass, including PT-BR text.

### Before upgrading

Keep a backup of your Cinderleaf state and Mods folders. 1.6.0 reads older install history, but writes a newer format that 1.5.0 cannot read. Do not run 1.5.0 against state already written by 1.6.0.

The sandbox is a separate Mods setup, not a separate Stardew Valley save. Downloads from mod sites remain manual.

### Windows portable

Download `cinderleaf-1.6.0-windows-portable.zip`, extract the whole folder, and run `Cinderleaf.exe`. It is a portable app, not an installer. SMAPI is not bundled; install it separately if you use it to run mods.

This hobby-project build is **unsigned**, so Windows may show a SmartScreen warning. The attached `.sha256` file lets you check the ZIP before deciding whether to run it. In PowerShell:

```powershell
Get-FileHash .\cinderleaf-1.6.0-windows-portable.zip -Algorithm SHA256
```

Compare the result with the hash in `cinderleaf-1.6.0-windows-portable.zip.sha256`. You do not need to disable SmartScreen globally.

Windows is the supported 1.6.0 portable download. The older experimental Linux build remains available under 1.5.0; a 1.6.0 Linux portable has not been validated on Linux.

The ZIP includes Cinderleaf's license and notices for bundled software. The matching Qt/PySide source archives are attached to this release separately; those libraries retain their own LGPL terms, not Cinderleaf's PolyForm terms.
